# Engineering Portfolio Manager v7.0.8

This release introduces a fourth investment category: **Sustained — Bugs and Defects**.

## Included

- Project editor category option
- Dashboard Project Mix count and active count
- Portfolio category filters
- Roadmap and reporting display
- CSV import/export support using the value `SUSTAINED`
- Existing `DPT` records continue to display as Skunkworks

No Supabase migration is required because `projects.category` is a text field.
