# Engineering Portfolio Manager v8.0.0

## Phase 1 — Terminology and navigation

This release is built directly from the deployed v7.2.5 Pi source.

- Projects are now called **Product Initiatives**.
- Roadmap is now called **Initiative Roadmap**.
- Development is now called **Development Support**.
- The product title is now **Engineering Portfolio Manager**.
- User-facing project terminology was updated across dashboards, editors, tables, reports, and exports.
- Existing Supabase schemas and internal code identifiers remain unchanged; no database migration is required.
