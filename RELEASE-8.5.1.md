# ATLAS v8.5.1 — Scorecard

- Adds a top-level Scorecard menu and editable KPI table.
- Includes Software MRR and Current Connections starter metrics.
- Supports add, edit, delete, target/current/average, status, team, category, owner, unit, and notes.
- Executive Report reads current MRR and connection count from the Scorecard.
- Uses Supabase when the migration is installed, with local browser fallback.
