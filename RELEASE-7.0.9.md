# Engineering Portfolio Manager v7.0.9

## Initiative Mix by Quarter

- Replaces the four project-type count cards with four fiscal-quarter donut charts.
- Each quarter shows NPD, CI, Skunkworks, and Sustained counts and percentages.
- Projects are assigned by planned start month using an October–September fiscal year.
- Includes fiscal-year selection and quarter drill-down buttons.
- Quarter project rows remain clickable and open the existing side editor.
