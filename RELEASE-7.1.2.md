# Engineering Portfolio Manager v7.1.2

## Quarterly sustained development work

- Restored a fourth quarterly dashboard category: **Sustained — Bugs and Enhancements**.
- The Sustained count is sourced from Development records whose Category is `Bug` or `Enhancement`.
- Development records are assigned to fiscal quarters by `start_date`.
- Quarter totals and percentages now combine portfolio projects with qualifying Development work items.
- Fiscal-year options include years represented by either project or Development start dates.
